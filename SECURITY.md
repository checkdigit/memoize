# Security Policy

## Supported Versions

These versions of `@checkdigit/memoize` are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| \>= 4.0 | :white_check_mark: |
| \< 4.0  | :x:                |

## Reporting a Vulnerability
